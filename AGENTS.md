# Delamain AI Development Harness (delamain)

This repository uses the **Delamain (`dlm`)** AI Development Harness (`profile: typescript`).

## Harness Configuration & Discovery

- **Manifest:** `.agents/harness.yaml` (versioned project configuration — edit to customize workflows, skills, or validators)
- **Lockfile:** `.agents/harness.lock` (generated by `dlm sync` — do not edit manually)
- **Workflows:** `.agents/workflows/*.yaml` (default workflow: `feature`)
- **Skills:** `.agents/skills/*/SKILL.md` (`planning, architecture, typescript-backend, tdd, code-review, security-review, handoff`)
- **Rules:** `.agents/rules/*.md`
- **Local State & Handoffs:** `.ai-harness-state/` (gitignored local SQLite telemetry, sessions, and handoff artifacts)

## Mandatory Agent Protocol

1. **Check Handoff & State First**: Run `dlm handoff verify` or inspect `.ai-harness-state/progress.json` before starting work on an existing branch. Never trust a prose summary without verifying `git status`, `git diff`, and test results.
2. **Follow Active Workflow Stages**: Inspect the workflow with `dlm workflow show feature`. Respect stage dependencies and mandatory verification gates.
3. **Preserve Security Floors**: Never enable `bypassPermissions` or `--dangerously-*` flags. Never read, print, or commit `.env` secrets.
4. **Verify Before Completion**: Run `dlm validate --run-validators` before concluding a task or creating a handoff (`dlm handoff create`).
